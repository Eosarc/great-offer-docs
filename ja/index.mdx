Great Offer AI は、面接資料、リアルタイムアシスタント、面接記録を一つのワークスペースにまとめます。履歴書と応募職種を準備し、モデルや回答形式を選択して、文字起こしと回答案を確認できます。終了後はサマリー、質問と回答、文字起こしで振り返ります。

## はじめて使う方へ

1. [アプリをインストールしてログイン](/ja/getting-started/install-and-sign-in)。
2. [マイク、システム音声、画面の権限を確認](/ja/setup/permissions)。
3. [履歴書](/ja/preparation/resumes)と[応募職種](/ja/preparation/jobs)を登録。
4. [アシスタントを設定して開始](/ja/launch/configuration)。
5. [チャット](/ja/assistant/text-chat)または音声で質問。
6. [面接を終了](/ja/assistant/end-session)して[記録を確認](/ja/review/records)。

全体の流れは[初回セッション](/ja/quickstart)をご覧ください。

| 面接官と自分の音声を設定 | [音声デバイス](/ja/assistant/audio) |

| ウィンドウを移動・折りたたむ | [ウィンドウ操作](/ja/assistant/window-controls) |
| 面接練習を行う | [練習の進め方](/ja/practice/rehearse) |
| フィードバックを読む | [面接サマリー](/ja/review/summary) |
| 利用枠と残り時間を確認 | [トライアルとプラン](/ja/account/plans-and-trial) |
