---
title: "インストールとログイン"
description: "デスクトップアプリをダウンロードして利用を始めます。"
---

デスクトップアプリのワークスペースで、資料の準備、アシスタントの起動、面接記録の確認を行います。

1. [Great Offer AI 公式サイト](https://greatoffer.ai/)のダウンロードページを開きます。
2. 使用するパソコンに合うインストーラーを選び、案内に従います。
3. アプリを開いてログインします。
4. ブラウザーに移動した場合は認証を完了してアプリに戻ります。
5. 左下のアカウントを確認します。購入時と同じアカウントを使用してください。

| メニュー | 用途 |
| --- | --- |
| ホーム | 準備の案内、職種、最近の記録、起動 |
| 面接記録 | 状態、時間、レポート |
| 履歴書 | アップロード、入力、確認、編集 |
| 志望職種 | 職種名、要件、会社 |
| ナレッジベース | プロジェクト、企業研究、参考資料 |
| クイックスタート | アプリ内の利用ガイド |
| サブスクリプションとクレジット | トライアル、契約、クレジット |
| アプリ設定 | 権限、デバイス、言語、バージョン |

ネット接続、履歴書、求人票、デバイス権限、利用可能なトライアル・契約・時間枠を準備します。システム要件と配布中のアプリはダウンロードページで確認してください。

次へ：[権限の確認](/ja/setup/permissions)または[初回セッション](/ja/quickstart)。
