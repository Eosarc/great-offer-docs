---
title: "面接の終了と再参加"
description: "折りたたみ、アプリ終了、面接終了の違いを確認します。"
---

練習や面接が済んだら**面接を終了**して記録とレポートに進みます。

1. ツールバーの**面接時間**を選びます。
2. **面接を終了**を選び、案内に従います。
3. ワークスペースに戻るまで待ちます。
4. 面接記録で状態を確認してレポートを開きます。

終了済みのセッションには再参加できません。続けるにはホームから新しく開始します。

| 操作 | 結果 |
| --- | --- |
| フローティングウィジェットに縮小 | 継続。ボールで復元 |
| アプリを終了 | 面接と時間消費は継続 |
| 面接を終了 | セッション終了。記録で閲覧 |

アプリを閉じただけなら、再起動し、ワークスペースの進行中セッションから再参加します。完全に終えるにはアシスタントで終了操作を行ってください。終了後はサマリーと記録を読み、**アカウントと請求 → 利用履歴を見る → クレジット使用状況** で消費を確認できます。
