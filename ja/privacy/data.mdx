Great Offer AI は利用する機能に応じ、履歴書、職種、資料、質問、音声、スクリーンショットを処理し、文字起こし、回答、振り返りを提供します。

## 処理と記録

文字起こしと AI 回答にはネット接続が必要です。関連する入力はサーバーと AI・文字起こしの提供事業者に送信されます。

終了して同期が完了すると、文字起こし、質問と回答、サマリーがクラウドに保存され、面接記録で閲覧・削除できます。ポリシーでは生の音声を一時処理し、サーバーの音声履歴として保持しないとしています。現在、元の音声の再生機能はありません。

アプリにはセッション復元と同期再試行のためのローカルデータもあります。クラウド記録の削除だけで端末の全データが消えるわけではありません。追加の削除はプライバシー窓口にご相談ください。

| 内容 | 管理先 |
| --- | --- |
| 履歴書、職種、資料 | 各一覧 |
| 質問、文字起こし、面接の要約 | 面接記録 |
| 権限 | アプリと OS |
| フィードバックと診断 | 設定 → ヘルプ |
| アカウント削除 | アカウントと請求 → プライバシー → アカウントを削除 |

必要な資料のみ送信し、不要な識別情報、パスワード、決済情報、私的な内容を除いてください。画像も必要な文脈に限定します。

## 任意の診断ログ

<strong>診断ログを添付（任意）</strong>は初期状態でオフです。有効にすると最近のログ、権限、実行環境が送信され、会話の文字情報が含まれる場合があります。提供に同意する場合のみ有効にしてください。

## 削除とポリシー

アカウント削除の警告を読み、指定の確認を行います。取り消せないため必要な資料を先に確認します。すべてのデータが即時削除されるとは限らず、法定の取引記録などはポリシーに従います。

[プライバシーポリシー](https://greatoffer.ai/privacy-policy)で保持期間と権利を確認し、[利用規約](https://greatoffer.ai/terms-of-service)も合わせてご確認ください。ご質問は [privacy@greatoffer.ai](mailto:privacy@greatoffer.ai) へお問い合わせください。
