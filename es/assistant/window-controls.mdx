---
title: "Ventanas y atajos"
description: "Mueve u oculta paneles, contrae el asistente y revisa respuestas."
---

Familiarízate con los controles antes de la sesión.

- Usa **Mostrar transcripción** u **Ocultar transcripción** en la barra para controlar su visibilidad. Ocultarla no detiene la transcripción.
- Pulsa el botón para ocultar el panel de respuestas. La generación en curso continúa.
- Arrastra el control de tamaño del panel de respuestas para cambiar su altura.
- Arrastra el área **Arrastrar asistente** de la barra para mover toda la ventana y no tapar la reunión o la pregunta.

Pulsa **Minimizar a widget flotante** y luego la burbuja para restaurar. La sesión continúa. **Menú → Abrir panel de control** permite volver al panel principal.

Las flechas recorren preguntas y respuestas. El contador indica la posición; los controles sin destino se desactivan.

## Atajos de teclado

| Función | macOS | Windows |
| --- | --- | --- |
| Anterior / siguiente pregunta | `Cmd + ←` / `Cmd + →` | `Ctrl + ←` / `Ctrl + →` |
| Respuesta de IA | `Cmd + ↵` | `Ctrl + ↵` |
| Analizar captura | `Cmd + Shift + S` | `Ctrl + Shift + S` |
| Chat | `Cmd + Shift + C` | `Ctrl + Shift + C` |
| Mover la ventana del asistente | `Cmd + Shift + flechas` | `Ctrl + Shift + flechas` |
| Contraer a burbuja flotante | `Cmd + H` | `Ctrl + H` |

`↵` es la tecla Intro. También puedes pulsar los controles directamente.

Al terminar, usa [Finalizar entrevista](/es/assistant/end-session).
