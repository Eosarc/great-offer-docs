---
title: "Conocer el asistente en tiempo real"
description: "Localiza transcripción, respuestas y controles."
---

El asistente admite preguntas de audio, texto y contenido en pantalla.

La **transcripción** muestra la conversación reconocida y se puede expandir u ocultar. El área de **respuestas** muestra preguntas y sugerencias; el texto continúa mientras se genera. Usa anterior y siguiente para revisar otras respuestas.

| Acción | Función |
|---|---|
| Ajustes de audio | Fuentes de voz y micrófono |
| AI Answer | Generar con el contexto de audio actual |
| Screenshot | Enviar un problema visual |
| Chat | Escribir preguntas |
| Duración de la entrevista | Tiempo y acciones de salida/finalización |
| Menú | Respuesta automática, modo invisible y espacio de trabajo |
| Minimizar a widget flotante | Contraer y restaurar |

Usa respuesta automática para seguir preguntas, **AI Answer** para controlar el momento, **Chat** para condiciones explícitas y capturas para material visual.

Identifica conclusión, evidencias y cifras antes de hablar con tus palabras. Verifica tu experiencia personal y responde en voz alta durante la práctica para revisar después tu expresión.
