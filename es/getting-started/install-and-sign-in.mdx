La aplicación de escritorio permite preparar materiales, iniciar el asistente y revisar entrevistas.

## Instalación

1. Visita la [web de Great Offer AI](https://greatoffer.ai/) y abre las descargas.
2. Elige el instalador adecuado para tu ordenador y sigue las instrucciones.
3. Abre la aplicación e inicia sesión.
4. Si se abre el navegador, completa el acceso y vuelve al cliente.
5. Comprueba la cuenta en la esquina inferior izquierda. Utiliza la misma cuenta con la que compraste el plan o los minutos.

| Sección | Función |
|---|---|
| Inicio | Preparación, puestos, registros recientes e inicio del asistente |
| Historial de entrevistas | Estado, duración e informes |
| Currículum | Subir, introducir, previsualizar y editar |
| Puestos objetivo | Guardar título, requisitos y empresa |
| Base de conocimientos | Documentos, proyectos e investigación |
| Inicio rápido | Orientación dentro de la aplicación |
| Suscripción y créditos | Prueba, suscripciones y paquetes de tiempo |
| Configuración de la aplicación | Permisos, dispositivos, idioma y versión |

Mantén la conexión a internet, prepara currículum y descripción del puesto, comprueba permisos y confirma que tienes acceso de prueba, suscripción o minutos. Los requisitos y clientes disponibles figuran en la página de descargas.
