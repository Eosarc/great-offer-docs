Great Offer AI は、面接資料、リアルタイムアシスタント、面接記録を一つのワークスペースにまとめます。履歴書と応募職種を準備し、モデルや回答形式を選択して、文字起こしと回答案を確認できます。終了後はサマリー、質問と回答、文字起こしで振り返ります。

## はじめて使う方へ

1. [アプリをインストールしてログイン](/jp/getting-started/install-and-sign-in)。
2. [マイク、システム音声、画面の権限を確認](/jp/setup/permissions)。
3. [履歴書](/jp/preparation/resumes)と[応募職種](/jp/preparation/jobs)を登録。
4. [アシスタントを設定して開始](/jp/launch/configuration)。
5. [チャット](/jp/assistant/text-chat)または音声で質問。
6. [面接を終了](/jp/assistant/end-session)して[記録を確認](/jp/review/records)。

全体の流れは[初回セッション](/jp/quickstart)をご覧ください。

| やりたいこと | ガイド |
|---|---|
| 経歴やプロジェクト資料を整理 | [面接資料の準備](/jp/preparation/materials-guide) |
| 回答の形式、長さ、口調を調整 | [回答の設定](/jp/launch/answer-preferences) |
| 面接官と自分の音声を設定 | [音声デバイス](/jp/assistant/audio) |
| 回答を生成するタイミングを選ぶ | [自動回答と手動回答](/jp/assistant/auto-and-manual) |
| 画面上の問題について質問 | [スクリーンショット分析](/jp/assistant/screen-analysis) |
| ウィンドウを移動・折りたたむ | [ウィンドウ操作](/jp/assistant/window-controls) |
| 面接練習を行う | [練習の進め方](/jp/practice/rehearse) |
| フィードバックを読む | [面接サマリー](/jp/review/summary) |
| 利用枠と残り時間を確認 | [トライアルとプラン](/jp/account/plans-and-trial) |

[よくある質問](/jp/faq)、[アプリ設定](/jp/settings/preferences)、[プライバシー](/jp/privacy/data)、[サポート](/jp/support/contact)もご利用ください。
