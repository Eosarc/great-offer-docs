---
title: "リアルタイムアシスタントの概要"
description: "文字起こし、回答、各種操作を確認します。"
---

アシスタントでは音声、文字、画面上の内容を使って質問できます。

**文字起こし領域**は認識した会話を表示し、展開・非表示を切り替えられます。**回答領域**には質問と提案が表示され、生成中は内容が続きます。左右のボタンで過去の回答に移動できます。

| 操作 | 用途 |
|---|---|
| オーディオ設定 | 面接官と自分のデバイス |
| AI Answer | 現在の音声文脈から生成 |
| Screenshot | 画面上の問題を送信 |
| Chat | 質問を入力 |
| 面接時間 | 時間と終了操作 |
| メニュー | 自動回答、ステルスモード、ワークスペース |
| フローティングウィジェットに縮小 | 折りたたみと復元 |

質問に追従するなら自動回答、自分でタイミングを選ぶなら**AI Answer**、条件を追加するなら**Chat**、視覚的な問題なら画面分析を使います。結論、根拠、数値を確認して自分の言葉で話してください。個人の経験は事実を確認し、練習では声に出して答えます。
