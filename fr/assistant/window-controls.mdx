Familiarisez-vous avec les commandes avant de commencer.

- Utilisez **Afficher la transcription** ou **Masquer la transcription** dans la barre pour régler sa visibilité. La masquer n’arrête pas la transcription.
- Cliquez sur le bouton de masquage du panneau de réponse. La génération en cours continue.
- Faites glisser la poignée de redimensionnement du panneau de réponse pour modifier sa hauteur.
- Faites glisser la zone **Déplacer l’assistant** de la barre pour déplacer toute la fenêtre et ne pas couvrir l’appel ou la question.

**Réduire en widget flottant** garde la session active ; cliquez sur la bulle pour restaurer. **Menu → Ouvrir le tableau de bord** revient au panneau principal.

Les flèches parcourent les questions-réponses et le compteur indique la position. Les actions indisponibles sont désactivées.

## Raccourcis clavier

| Fonction | macOS | Windows |
| --- | --- | --- |
| Question précédente / suivante | `Cmd + ←` / `Cmd + →` | `Ctrl + ←` / `Ctrl + →` |
| Réponse IA | `Cmd + ↵` | `Ctrl + ↵` |
| Analyser la capture | `Cmd + S` | `Ctrl + S` |
| Chat | `Cmd + C` | `Ctrl + C` |
| Réduire en widget flottant | `Cmd + H` | `Ctrl + H` |

`↵` correspond à la touche Entrée (Retour). Vous pouvez aussi cliquer directement sur les commandes.

Utilisez [Terminer l’entretien](/fr/assistant/end-session) à la fin.
