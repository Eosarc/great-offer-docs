title: "Add and manage resumes"
description: "Upload a file or enter your resume text to provide personal context."
---

Open **Resumes** in the workspace to upload, preview, and edit resumes. Use recognizable names, such as “Product Manager — Enterprise” or “Software Engineer — Backend.”

## Upload a file

1. Select **Upload Resume**.
2. Enter a **Resume Title**.
3. Drop a file or select it from your computer. PDF, DOCX, TXT, and MD are supported, up to 5 MB per file.
4. Select **Upload**, then confirm the content and save as prompted.
5. Return to the list and select **Preview** to check the text.

Use a file with selectable text and clearly separated experience, responsibilities, and results.

## Enter text manually

In the upload window, choose **No file? Switch to manual entry**, enter a title, paste your text, and save.

Include your target direction, main experience, recent responsibilities, two or three representative projects, skills, education, and languages. Describe project background, your actions, and the outcome.

## Preview and edit

Select **Preview** to read the content or **Edit** to update and save it. Choose the appropriate version in the **Resume** menu when launching.

Use the delete action for materials you no longer need, checking the selected item and confirmation first.
