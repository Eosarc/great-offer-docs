---
title: 配置并启动面试助手
description: 为本场会话选择简历、岗位、模型、文档和回答方式。
---

在 **工作台首页** 点击 **启动助手**，打开 **启动你的面试助手**。开始前，准备好简历、目标岗位、设备权限与可用权益。

## 逐项确认配置

| 配置项 | 如何选择 |
|---|---|
| 简历 | 必选，选择适合本次岗位的简历版本 |
| 岗位 | 必选，确认岗位名称与公司 |
| AI 模型 | 从当前可用列表选择模型 |
| 文档（可选） | 选择一份相关知识库文档，或不使用文档 |
| 面试语言 | 选择 AI 回答的输出语言，或使用自动选项 |
| 自动回答 | 决定是否自动识别提问并生成回答 |
| 回答偏好 | 设置回答格式、长度与表达语气 |

选择完毕后，点击 **开始面试**，等待进入助手界面。会话开始后，可在 **音频设置** 查看设备与连接状态。

## 推荐的首次配置

先选择熟悉的简历与岗位。回答偏好可使用 **回答 + 要点 / 适中 / 自然**，兼顾完整表达与快速浏览。接着用一个明确的文字问题熟悉回答区域。

需要自行决定生成时机时，可以在启动配置中关闭自动回答，进入会话后使用 **AI 回答** 或 **对话**。

## 下一次如何使用

再次启动时，重新核对当前显示的资料和偏好，再点击开始。面试方向改变时，先在工作台更新资料。完成本场后，通过 **面试时长 → 结束面试** 收尾。
