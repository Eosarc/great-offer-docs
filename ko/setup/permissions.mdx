**앱 설정 → 면접 접근 권한**에서 현재 장치에 필요한 권한과 상태를 확인합니다. 표시되는 항목은 클라이언트에 따라 다릅니다.

| 권한 | 용도 |
|---|---|
| 마이크 | 자신의 음성 전사와 복기 |
| 시스템 오디오 | 회의 앱의 면접관 음성 |
| 화면 접근 | 화면 분석을 위한 캡처 기능. 일부 시스템에서는 오디오 캡처에도 필요 |

마이크와 시스템 오디오는 서로 다른 소스이므로 둘 다 확인합니다.

## 권한 확인 및 허용

1. 앱에서 권한 상태를 봅니다.
2. 허용되지 않은 항목에서 해당 권한 허용 또는 설정 버튼을 선택합니다.
3. 앱과 운영체제 안내에 따라 Great Offer AI의 접근을 허용합니다. 시스템 설정을 열었다면 완료 후 앱으로 돌아옵니다.
4. 앱으로 돌아와 확인합니다. 재시작이 필요하면 진행 중인 면접을 먼저 종료합니다.

권한 이름, 설정 위치, 허용 절차는 운영체제와 버전에 따라 다릅니다. 현재 장치의 안내를 따르세요.

헤드폰이나 외부 장치를 연결한 후 회의 앱과 어시스턴트의 선택을 맞추고 연습 통화로 두 음성을 확인하세요.
