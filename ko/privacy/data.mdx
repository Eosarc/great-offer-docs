Great Offer AI는 사용하는 기능에 따라 이력서, 직무, 문서, 질문, 음성, 스크린샷을 처리해 전사, 제안, 복기를 제공합니다.

## 처리와 기록

전사와 AI 답변은 인터넷이 필요합니다. 관련 입력은 서버와 AI 또는 전사 제공업체에 전송됩니다.

종료 및 동기화 후 전사, 질의응답, 요약은 클라우드에 저장되며 면접 기록에서 조회하거나 삭제할 수 있습니다. 정책상 원본 오디오는 일시 처리하고 서버의 음성 이력으로 보관하지 않습니다. 현재 원본 음성 재생은 제공하지 않습니다.

앱에는 세션 복구와 동기화 재시도용 로컬 데이터도 있습니다. 클라우드 기록을 삭제해도 기기의 모든 데이터가 지워지지는 않습니다. 추가 삭제는 개인정보 지원에 문의하세요.

| 내용 | 관리 위치 |
|---|---|
| 이력서, 직무, 문서 | 해당 목록 |
| 질문, 전사, 요약 | 면접 기록 |
| 권한 | 앱 및 OS 설정 |
| 피드백과 진단 | 설정 → 도움말 |
| 계정 삭제 | 계정 → 개인정보 |

필요한 자료만 보내고 불필요한 식별 정보, 비밀번호, 결제 정보, 개인 내용을 제거합니다. 화면도 필요한 맥락으로 제한하세요.

## 선택적 진단 로그

진단 로그 첨부는 기본적으로 꺼져 있습니다. 켜면 최근 로그, 권한, 실행 환경이 전송되며 대화 문자가 포함될 수 있습니다. 해당 정보 제공에 동의할 때만 켜세요.

## 삭제와 정책

영구 삭제 경고를 읽고 요청된 확인을 진행합니다. 취소할 수 없으므로 보관할 자료를 먼저 확인하세요. 모든 데이터가 즉시 없어지는 것은 아니며 법적 거래 기록과 기타 보관은 정책을 따릅니다.
