description: "데스크톱 앱을 다운로드하고 작업 공간에 접속합니다."
---

앱에서 자료를 준비하고 어시스턴트를 시작하며 면접 기록을 확인합니다.

1. [Great Offer AI 웹사이트](https://greatoffer.ai/)에서 다운로드를 엽니다.
2. 컴퓨터에 맞는 설치 파일을 선택하고 안내를 따릅니다.
3. 앱을 열고 로그인합니다.
4. 브라우저가 열리면 인증을 마치고 앱으로 돌아옵니다.
5. 왼쪽 아래 계정을 확인합니다. 구매할 때 사용한 계정으로 로그인하세요.

| 메뉴 | 용도 |
|---|---|
| 홈 | 준비 안내, 직무, 최근 기록, 시작 |
| 면접 기록 | 상태, 시간, 보고서 |
| 이력서 | 업로드, 입력, 미리보기, 편집 |
| 지원 직무 | 직무명, 요구 사항, 회사 |
| 지식 베이스 | 프로젝트, 기업 조사, 참고 문서 |
| 빠른 시작 | 앱 내 준비 안내 |
| 구독 및 크레딧 | 체험, 구독, 시간 팩 |
| 앱 설정 | 권한, 장치, 언어, 버전 |

인터넷, 이력서, 채용 공고, 장치 권한과 사용 가능한 체험·구독·시간을 준비합니다. 시스템 요구 사항과 배포 중인 앱은 다운로드 페이지에서 확인하세요.
