title: "답변 설정"
description: "읽고 말하기 편하도록 형식, 길이, 말투를 조정합니다."
---

**홈 → 어시스턴트 시작 → 답변 설정**을 열고 미리보기를 확인합니다.

| 형식 | 용도 |
|---|---|
| 전체 답변 | 연결된 설명 읽기 |
| 답변 + 요점 | 설명과 핵심 확인 |
| 요점만 | 빠르게 읽고 자신의 말로 표현 |

길이는 **짧게, 보통, 자세히**, 말투는 **자연스럽게, 격식 있게** 중에서 고릅니다. 익숙한 질문은 짧게, 논리를 공부하려면 자세한 답변을 활용하세요.

1. 설정 패널을 엽니다.
2. 세 항목을 고릅니다.
3. 미리보기의 가독성을 확인합니다.
4. 시작 전 설정 요약을 확인합니다.

미리보기는 고정 예시이며 실제 답변은 질문과 자료에 따라 달라집니다. **답변 + 요점 / 보통 / 자연스럽게**로 시작해 읽기 속도에 맞추고 자신의 말로 소리 내어 연습하세요.
