홈에서 **어시스턴트 시작**을 선택합니다. 이력서, 직무, 권한, 이용 권한을 준비하세요.

| 설정 | 선택 |
|---|---|
| 이력서 | 필수, 직무에 맞는 버전 |
| 직무 | 필수, 이름과 회사 확인 |
| AI 모델 | 현재 목록에서 선택 |
| 문서 | 관련 문서 하나 또는 없음 |
| 면접 언어 | AI 출력 언어 또는 자동 |
| 자동 답변 | 질문 감지 후 자동 생성 여부 |
| 답변 설정 | 형식, 길이, 말투 |

</Frame>

면접을 시작하고 오디오 설정에서 장치와 연결을 확인합니다.

처음에는 익숙한 자료와 **답변 + 요점 / 보통 / 자연스럽게**를 사용하고 채팅 질문을 해 보세요. 시점을 직접 정하려면 자동 답변을 끄고 AI 답변이나 채팅을 사용합니다.

매번 자료와 설정을 확인하고 방향이 바뀌면 업데이트합니다. 끝나면 **면접 시간 → 면접 종료**를 사용합니다.
