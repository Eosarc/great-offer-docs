시작 전에 조작에 익숙해지세요.

- 도구 모음의 **전사 표시** 또는 **전사 숨기기**로 전사 영역의 표시를 전환합니다. 숨겨도 전사는 계속됩니다.
- 답변 패널의 숨기기 버튼을 누르면 패널이 숨겨집니다. 진행 중인 답변 생성은 계속됩니다.
- 답변 패널의 크기 조절 핸들을 드래그해 높이를 바꿉니다.
- 도구 모음의 **도우미 이동** 영역을 드래그해 창 전체를 옮기고 통화나 질문을 가리지 않게 합니다.

**플로팅 위젯으로 최소화**를 누르면 창이 작아집니다. 위젯을 클릭하면 복원됩니다. 세션은 계속됩니다. **메뉴 → 대시보드 열기**로 돌아갈 수 있습니다.

좌우 버튼으로 질의응답을 이동하고 카운터로 위치를 확인합니다. 이동할 곳이 없는 버튼은 비활성화됩니다.

## 키보드 단축키

화면 분석, 채팅, 창 접기, 질의응답 이동 단축키는 현재 버튼이나 메뉴 옆 안내를 확인하세요. 사용 가능한 단축키와 키 조합은 운영체제와 버전에 따라 다를 수 있습니다. 해당 버튼을 직접 눌러도 됩니다.

완료 후 [면접 종료](/ko/assistant/end-session)를 사용합니다.
