---
title: "면접 종료와 재참가"
description: "접기, 앱 종료, 면접 종료를 구분합니다."
---

완료했다면 면접 종료를 사용해 기록과 보고서로 이동합니다.

1. 도구 모음의 면접 시간을 누릅니다.
2. 면접 종료를 선택하고 안내를 따릅니다.
3. 작업 공간으로 돌아올 때까지 기다립니다.
4. 기록에서 상태를 확인하고 보고서를 엽니다.

  <img src="/images/client/end-session.png" alt="Quit App과 End Interview가 별도 동작으로 표시된 면접 시간 메뉴." width="480" />
</Frame>

완료된 세션에는 재참가할 수 없습니다. 계속하려면 홈에서 새로 시작합니다.

| 동작 | 결과 |
|---|---|
| 버블로 접기 | 계속 진행, 클릭으로 복원 |
| 앱 종료 | 면접과 시간 사용 계속 |
| 면접 종료 | 완료 후 기록으로 확인 |

앱만 닫았다면 다시 열어 진행 중인 세션의 재참가를 이용합니다. 완전히 마치려면 어시스턴트에서 종료하세요. 이후 요약, 질의응답, 전사를 확인하고 시간 팩 상세에서 사용량을 볼 수 있습니다.
