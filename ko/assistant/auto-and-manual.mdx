---

시작 설정이나 세션 메뉴에서 자동 답변을 켜면 감지한 질문에 따라 제안이 표시됩니다. 생성 중에는 결론부터 읽고 추가 조건은 채팅으로 입력하세요.

## 직접 생성하기

1. 자동 답변을 끕니다.
2. 전사에 질문이 나타나면 맥락을 확인합니다.
3. **AI 답변**을 누릅니다.
4. 답변을 읽습니다.

자동 답변을 꺼도 전사는 계속할 수 있어 전체 질문을 들은 뒤 요청할 수 있습니다.

| 목적 | 방법 |
|---|---|
| 질문 따라가기 | 자동 답변 |
| 먼저 듣고 생성 | AI 답변 |
| 질문과 출력 조건 명시 | 채팅 |

예: “배경, 행동, 결과 순서로 1분 답변을 만들어 주세요.”
