시작 후 음성, 문자, 화면의 내용으로 질문할 수 있습니다.

**전사본 영역**은 인식한 대화를 보여 주며 펼치거나 숨길 수 있습니다. **답변 영역**에는 질문과 AI 제안이 표시되며 생성 중에는 계속 내용이 추가됩니다. 좌우 버튼으로 이전 답변을 봅니다.

| 도구 | 용도 |
|---|---|
| 오디오 설정 | 면접관과 마이크 장치 |
| AI Answer | 현재 음성 맥락에서 생성 |
| Screenshot | 화면 문제 전송 |
| Chat | 질문 입력 |
| 면접 시간 | 시간과 종료 동작 |
| 메뉴 | 자동 답변, 스텔스 모드, 작업 공간 |
| 플로팅 위젯으로 최소화 | 접기와 복원 |

질문을 따라가려면 자동 답변, 시점을 정하려면 AI 답변, 조건 추가는 채팅, 시각 자료는 화면 분석을 사용합니다. 결론, 근거, 숫자를 확인한 뒤 자신의 말로 답하세요. 개인 경험은 사실을 검토하고 연습에서는 소리 내어 말합니다.
