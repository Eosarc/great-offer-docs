助手提供区域显隐、位置调整和悬浮球操作。可以在面试前先熟悉这些控制，让阅读建议更顺手。

## 显示和隐藏内容

- 使用工具栏的 **显示转录窗口** 或 **隐藏转录窗口** 控制转录区域的显隐。隐藏后，转录仍会继续。
- 点击回答区域的隐藏按钮，暂时隐藏该区域。生成中的回答不会因此停止。
- 拖动回答区域的高度调整手柄，改变区域高度，为内容留出合适空间。
- 拖动工具栏中的 **拖动面试助手** 区域，移动整个助手窗口，避免遮挡通话或题目。

## 收起为悬浮球

点击 **收起为悬浮球**，助手会缩小。需要继续阅读时，点击悬浮球恢复。收起后会话仍在进行。

需要回到工作台时，使用 **菜单 → 打开工作台**。

## 回看回答

回答区域的左右按钮用于查看前后问答。旁边的计数帮助你判断当前所在位置；没有可翻页内容时，对应按钮不可用。

## 快捷键

| 功能 | macOS | Windows |
| --- | --- | --- |
| 上一题／下一题 | `Cmd + ←` / `Cmd + →` | `Ctrl + ←` / `Ctrl + →` |
| AI 回答 | `Cmd + ↵` | `Ctrl + ↵` |
| 分析截图 | `Cmd + Shift + S` | `Ctrl + Shift + S` |
| 对话 | `Cmd + Shift + C` | `Ctrl + Shift + C` |
| 拖动助手窗口 | `Cmd + Shift + 方向键` | `Ctrl + Shift + 方向键` |
| 收起为悬浮球 | `Cmd + H` | `Ctrl + H` |

`↵` 为回车键。也可以直接点击对应控件操作。

完成面试后，使用[结束面试](/zh/assistant/end-session)停止本场会话。
