桌面应用是使用实时面试助手的入口。登录后，你可以在工作台准备资料、启动助手和回看面试记录。

## 安装与登录

1. 打开 [Great Offer AI 官网](https://greatoffer.ai)，进入下载应用入口。
2. 选择适合当前电脑的安装包，按安装向导完成安装。
3. 打开 Great Offer AI，按照登录页面完成账户登录。
4. 如登录过程跳转到浏览器，完成后按照提示返回客户端。
5. 在工作台左下角确认当前账户。已有套餐或时长时，使用购买时的同一账户登录。

## 认识工作台

| 入口 | 用途 |
|---|---|
| 首页 | 查看准备指引、目标岗位、最近记录并启动助手 |
| 面试记录 | 查看会话状态、时长与面试报告 |
| 简历 | 上传、填写、预览和编辑简历 |
| 目标岗位 | 保存岗位名称、岗位要求和公司 |
| 知识库 | 管理项目资料、公司研究和参考文档 |
| 快速入门 | 查看应用内的准备与启动指引 |
| 订阅与额度 | 查看试用、订阅套餐和时长包 |
| 应用设置 | 检查权限、设备、语言与版本 |

## 开始前准备好这几项

保持网络连接；准备一份简历和一份目标岗位说明；在应用设置中检查设备权限；确认账户具有可用试用、套餐或时长额度。具体安装要求和可选客户端以官网下载页为准。
